# Fortune Cookie for the Liquidated Trader

One fortune cookie line (113 characters, 20 words) for a crypto trader who just got liquidated, written by a program to `/output/entry.txt`. Node 22, standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```

## The line

> Your lucky numbers are 0, 0, and 0. The cookie was leveraged too. You are the market's favourite cautionary tale.
